# Codebase Map

Кроссплатформенное desktop-приложение на Flutter для анализа локальных проектов
и визуализации зависимостей между исходными файлами.

## Платформы

macOS, Windows и Linux. В репозитории созданы native runners для всех трёх
платформ. Сборка и запуск каждой платформы выполняются на соответствующей ОС
с установленным Flutter SDK и её desktop toolchain.

## Текущий статус

Начальный каркас: точка входа, приложение Material, экран-заглушка и widget/smoke
тесты. Сканирование, анализ исходников и граф пока не реализованы.
AI-функции, backend, база данных и Git-анализ в текущий этап не входят.

## Структура

- `lib/main.dart` — точка входа.
- `lib/app/` — сборка приложения и общие настройки Flutter.
- `lib/ui/` — экраны и UI-компоненты.
- `lib/core/file_system/` — будущее сканирование файлов локального проекта.
- `lib/core/analysis/` — будущая координация анализа и общие результаты.
- `lib/core/dependency_graph/` — будущая модель и построение графа, независимо от UI.
- `lib/analyzers/dart/` — будущий анализатор Dart/Flutter.
- `lib/visualization/` — будущие виджеты представления графа.
- `test/` — smoke/widget tests каркаса.

Зарезервированные каталоги содержат только описания назначения. Интерфейсы,
сервисы, DI и дополнительные пакеты появятся при реальной необходимости.
Планируется держать ядро и анализаторы независимыми от Flutter UI. Общий формат
результатов анализа будет определён при реализации Dart-анализатора; затем
анализаторы TypeScript, Python и других языков смогут использовать этот формат.

## Разработка

Проверено с Flutter 3.47.5 (stable) и Dart 3.13.4.

```sh
flutter pub get
flutter analyze
flutter test
flutter run -d macos   # на macOS
flutter run -d windows # на Windows
flutter run -d linux   # на Linux
```

`pubspec.lock` следует хранить в Git для воспроизводимых зависимостей приложения.

В исходном окружении macOS `flutter doctor` обнаружил неполную установку Xcode
и отсутствие CocoaPods. Native-сборка macOS пока не проверена; Windows/Linux
нужно проверить на соответствующих ОС. Android SDK отсутствует и для этого
desktop-проекта не требуется.
